# Project Documentation: Clarify Prompt Evaluation Framework

---

## 1. Context & Purpose

This framework is a professional-grade prompt evaluation pipeline designed to benchmark, audit, and validate the LLM prompt iterations powering our core AI components. This tool measures response accuracy and prevents "prompt drift" or formatting structural breaks before updates are deployed.

The production-level engine driving this project is **Clarify**, a mobile app I developed to support couples experiencing communication gaps. Clarify integrates Nonviolent Communication (NVC) principles, an AI relationship coach, and daily engagement tools to help partners defuse unspoken tensions and refuel their relationships. You can view Clarify on the App Store : [https://apps.apple.com/us/app/clarify-couple-dairy/id6761012915](https://apps.apple.com/us/app/clarify-couple-dairy/id6761012915).

Far from a simple sandbox script, this framework serves as the structural foundation for the future automated processing of real data within the Clarify ecosystem.

---

## 2. System Architecture

The framework is built using a decoupled, modular architecture to ensure that the AI model layer can be swapped out instantly without impacting the grading logic.

```
clarify-ai-core/
│
├── data/
│   └── raw_data.json         <-- Input dataset
│
├── results/
│   ├── eval_report_v1.csv    <-- Permanent structured analytics storage
│   └── performance_chart.png <-- Matplotlib generated data visual
│
├── dataset_loader.py         <-- Handles JSON data ingestion
├── llm_client.py             <-- Connects to Google Gemini API & parses text
├── evaluator.py              <-- Structural, Categorical, & Length validation
├── visualizer.py             <-- Converts Pandas DataFrames into charts
└── main.py                   <-- Pipeline conductor & orchestrator

```

## 3. Installation & Setup

Follow these exact steps to deploy the evaluation engine locally on your machine.

### Prerequisites

- Python 3.11 or higher installed on your system.
- A valid Google Gemini API Key.

### Step-by-Step Installation

1. **Clone and navigate to the project directory:**

```bash
cd /Users/poupi/Desktop/Clarify/clarify-ai-core

```

1. **Initialize and activate the local virtual environment:**

```bash
   python3 -m venv venv
   source venv/bin/activate

```

1. **Install required production dependencies:**

```bash
   pip install google-genai pandas matplotlib
   pip freeze > requirements.txt

```

1. **Configure your environment variables:**

Create a `config.py` file in the root directory and add your secret API key:

```python
   GEMINI_API_KEY = "your_actual_api_key_here"

```

1. **Execute the pipeline orchestrator:**

```bash
python main.py

```
